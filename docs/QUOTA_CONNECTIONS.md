# 额度连接与发行边界

## 连接一次，再持续查询

「连接」→ 选择实际产品 → API Key 或官方登录 → 验证真实用量 → 返回首页。

会员、API 钱包和 Audio 会员是不同产品，不共享余额。每个连接保留自己的单位、更新时间和官方重置时间。读取失败不会删除仍有效的登录；只有明确断开、官方过期或撤销授权才需要重新连接。

查询源通常约 30 秒刷新，服务商结算可能滞后。网站连接在 macOS 14+ 使用独立持久配置，不读取其他应用凭证、浏览器 Cookie、聊天内容或模型生成内容。临时预览不接入个人账户。macOS 13 不会为了兼容而退回共享浏览器存储。

## 安全范围

- API Key 保存在 Keychain，不写入工作区、仓库或测试截图。
- 后台读取不弹系统授权；拒绝、锁定或失败会暂停并报告，不反复自动要求密码。
- 登录、账户替换、迁移和断开必须是用户的明确操作。
- 配音积分与 MiniMax API 充值额分离；Cursor 中的 Grok 不等于独立 SuperGrok。
- 重置公告是第三方消息来源，不等于某个账户已实际恢复额度。
- 未读取的值、过期值、缺少重置日期和未知任务数保持未知。

## 固定凭证组件不是通用签名

源码包含 `PaulCredentialAgent`、`PaulCredentialAgentV2` 和隔离回归。它们属于维护者个人发行配置：验证指定父应用与固定证书，普通更新保留已发行组件的字节和签名。v2 迁移只处理 Paul 的三个专用凭证命名空间，不能推广成读取任意应用的 Keychain。

公开打包不复制维护者的组件或证书私钥，也不假装普通自签应用具有维护者身份。修改校验或更换组件需要独立安全设计与迁移验证；不要通过删除校验、放宽证书要求或修改其他应用权限让测试变绿。

公开源代码的正常运行使用自己的 Keychain 访问路径。临时签名或不同签名的重编译不能保证跨版本免授权。通用 Developer ID、公证、稳定凭证组件和可验证的自动更新渠道是后续发行工作，不包含在这个源码 PR 中。

## 工作区保持兼容

公开版本保留 `PaulNotch` 启动入口、Bundle ID 和 `~/Library/Application Support/Paul Notch` 数据位置，不导入维护者个人工作区。预览使用独立临时目录，已有数据不会被静默搬迁。

普通公开启动允许显式连接自己的 API / 会员账户，并保存自己完成并验证的网站连接；预览不允许。该额度能力不启用其他受限的旧集成，也不放宽固定凭证组件的身份检查。`test-public-runtime.sh` 和 `test-quota-keychain.sh` 验证这些边界，跨进程恢复、失败保留和断开清理由 WebKit 合成测试覆盖。真实账户持续使用须逐个验收，不能用合成测试代替。
