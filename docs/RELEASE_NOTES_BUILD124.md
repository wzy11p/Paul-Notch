## 轻量边界

动效使用固定上限与既有可见性/省电策略。此次不降低画质、帧率、图片尺寸或额度更新频率。发行包会在签名前剥离非运行必需的调试/本地符号；未剥离的构建产物仍留在开发目录，便于诊断。包体减小不是运行内存同比下降的承诺。

`scripts/test-release-package.sh` 比较打包前后所有 Mach-O 运行 section 的实际字节、品牌资源、图标、许可证和最终签名；它不以源代码文本中出现某条命令来代替验证。开发构建不做这种剥离。

## 验证与限制

新增原生验证器覆盖菜单让位、贴顶展开、拖放/双击回位、玻璃生命周期、粒子水体、单双额度和卡片配色。原生 UI 组需要交互式 macOS 会话；GitHub CI 执行可在 runner 上运行的模型、连接、安全、公开边界与打包检查。测试命令和实际 CI 结果应一并查看，不把构建成功当作全部行为已验收。

公开的现有数据路径、Bundle ID、源码入口、Swift 6 摄像头并发修复、关闭链接元数据联网及独立 Keychain 边界均保留。Muse 额外余额没有官方到期事实时仍显示未知，不声称永久有效。
